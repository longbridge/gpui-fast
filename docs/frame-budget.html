内容全变时是 −16%。这个差距不是噪声，而是提升的本质：能省下来的，是没有变化的那部分的工作。

提升随「有多少东西真的变了」而变

提升来自哪一段

一帧走三遍元素树：build 建树并要布局，prepaint 算位置（布局在这里），paint 生成交给 GPU 的图元。这三段是帧内 Instant 直接测的，不受合成器影响。

prepaint 从 5.96 ms 掉到 0.46 ms，是 −92%。静止帧里布局的开销已经接近于零。而 paint 的 4.7 ms 纹丝不动，三种变化比例下都一样——这一段和「变了多少」无关。

数据由 cargo run -p gpui --example grid_frames --release -- 50 50 <变化比例> 产生，两个版本交替运行以排除漂移。相位时间为帧内计时，与合成器无关；整帧时间取三次最小值，因为外部干扰只会让帧变慢。
